# TechUniversity Portal

A modern, tech-inspired academic portal with role-based access for Students and Class Representatives (CRs).

## Features
- **Dark/Cyberpunk UI**: Glassmorphism, neon accents, and smooth animations.
- **Role-Based Login**: Distinct access for Students and CRs.
- **Security**: Mandatory password change on first login.
- **Dashboard**: Access to Maths, Physics, SNW, PSP materials.
- **CR Privileges**: Upload content specific to their assigned subject.
- **Interactive**: Doubts posting and tech quotes.

## How to Run
1. Open `index.html` in any modern web browser.
2. No server required (uses LocalStorage).

## Default Credentials (First Time Login)
**For Students:**
- ID: `STUDENT`
- Password: `12345`

**For CRs:**
- ID: `CR`
- Password: `12345`

*Note: You will be prompted to set your own unique ID and Password upon first login.*

## Developer Notes
- Built with Vanilla HTML/CSS/JS.
- Data is persisted in the browser's LocalStorage.
